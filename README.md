# 白雪夜 · 个人成长工作台（首版）

这是原「视觉拆解训练室」扩展后的静态工作台首版：黑白橙高对比、像素化的编辑台风格，适合先部署到 CloudBase 静态托管。

## 这一版已经可以用

- TAB 0：总看板，汇总训练、灵感、待拍板和工具队列。
- TAB 1：设计训练，含主图、详情页、十分钟拆解、店铺首页、主 KV 等入口；可上传参考图、填写复盘并存档。
- TAB 2–4：英语、写作、声乐的规划入口。
- TAB 5：成长清单，保留原话、自动给出本地关键词分类建议、编号、手动调整状态。
- TAB 6：视频转笔记工具箱，先收集授权内容的处理需求，尚不抓取或下载任何平台视频。
- 灵感库：汇总上述本地记录；右上角可导出 JSON 备份。

所有记录只存在当前浏览器的 `localStorage` 中。没有 CloudBase SDK、没有 OpenAI Key、没有云函数、没有模型调用，因此不会产生 API 或模型费用。

## CloudBase 静态托管部署

1. 在 CloudBase 控制台创建环境，开启「静态网站托管」。
2. 从本仓库下载或复制 `index.html`，上传到静态托管的根目录。
3. 使用系统生成的域名访问；确认正常后，再绑定自己的域名（可选）。

此版本是单文件静态站点，不需要构建命令。后续接入时，将按顺序添加 CloudBase 登录、数据库同步、图片云存储，再通过云函数接 GPT；密钥不会放在前端或 GitHub。
